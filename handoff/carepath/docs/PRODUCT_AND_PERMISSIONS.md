# 产品与权限说明

CarePath 面向老年用户与照护者，解决收到医疗费用文件后「文件是什么意思、接下来做什么、可以让谁帮忙」的问题。目标是帮助理解和准备求助，不承诺援助资格或费用减免。

## 主流程

从「帮我读文件」进入 → 选择清晰/模糊的虚构账单 → 白话解释与原文核对 → 分步确认信息（允许不确定）→ 集中检查和修改 → 保存咨询清单。遇到无法辨认的金额或其他疑问，可在流程中请求人工复核；先查看共享范围并同意，再建立模拟请求，之后可撤回。

人工请求使用当时已确认答案的快照；修改草稿不会悄悄改变已经共享的内容。专业人员工作台独立于照护者权限。

## 照护者的三个阶段

```text
未授权
  老人：选 Anna → 文件/清单查看范围 → 可选管理 → 复核并确认
  照护者：等待，不能查看内容
       ↓ 本人明确同意
授权生效
  老人：查看进展、调整范围、发起撤回
  照护者：仅查看指定内容；有单独管理权限才可勾选任务、补充问题
       ↓ 老人确认撤回
授权结束
  老人：保留文件与原有进展，可再次授权
  照护者：已打开的文件/清单停止显示，不能自行恢复
```

| 能力 | 老人本人 | 照护者 |
| --- | --- | --- |
| 选择共享对象、范围 | 可以，明确确认后生效 | 不可以 |
| 查看共享的一份文件 | 可以 | 仅文件查看获准且授权有效时 |
| 查看该文件的下一步清单 | 可以 | 仅清单查看获准且授权有效时 |
| 标记任务、补充预设咨询问题 | 可以查看协作结果 | 另需清单管理权限 |
| 修改本人的其他档案回答 | 主流程内可修改 | 不可以 |
| 撤回/重新授权 | 可以 | 不可以 |
| 代付、提交申请、转授权 | 原型不提供 | 不提供 |

撤回会影响当前已打开的照护者页面并在刷新后保持；不会追回已保存的副本，界面已说明。文件、清单与操作权限需分别说明，不能把「可查看」等同于「可代办」。

## 实现范围

两个手机角色是同源 localStorage 中的模拟视图，不是登录用户或安全边界。没有真实邀请送达、上传、OCR/LLM请求、资格判断、转账、外部消息或申请提交。朗读使用浏览器 speechSynthesis，是否可用取决于设备/浏览器。

所有姓名、医院和金额为演示数据。情境照片已标记为 AI 生成示意，不是真实研究参与者。尚未开展真实访谈和可用性测试，后续按研究方案收集匿名证据，再补入作品集。
